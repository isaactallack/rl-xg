    Auto-tracking your games

    The dashboard picks up replays three ways:

    1. Rockpload (bundled).
      It starts with the dashboard, already set up to send ranked 2v2 replays here (website RL xG dashboard → /upload). The first time, sign in with your Epic account in Rockpload's window. By default it uploads when you close Rocket League (and every ~45 min); turn off No Upload if player is online in its behaviour settings to get games while you're still playing.
    2. Folder watching. Saved replays in the watched folders are analysed automatically:
      Add more with python -m rlxg.dashboard --watch "C:\path\to\folder" (e.g. Rockpload's FileSystem storage folder).
    3. Manual. Drag .replay files anywhere onto this page, or use Add replays.

    Only 2v2 games are analysed (the model is trained on 2v2).
